# Format

The format itself: what an ensemble IS, and the rules that hold whatever it
describes. It has **no domain** — no hit points, no shields, no closed list of
what a zone may mean — because the same file has to describe a fortification, a
botanic garden and a lighting rig. Anything domain-specific rides in `features`,
`kind` and open `values`, and arrives from a preset.

# Presets

Vocabularies a consumer opts into. Neither is re-exported from the package root:
the format has no domain, so you name the one you want.

```typescript
import { registerWorldPreset } from "tosijs-3d-ensemble/presets/world";
import { registerCombatPreset } from "tosijs-3d-ensemble/presets/combat";
```
